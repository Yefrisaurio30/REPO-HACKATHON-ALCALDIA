# Guion de pitch — VibraLink · Mente Sana Joven

Duración objetivo: **5 minutos** (22 de octubre de 2026, UNIMETA TECH).

## Estructura propuesta

1. **Apertura — 30 s**
   - Problema: jóvenes de 18 a 28 años en Villavicencio que necesitan orientación en salud
     mental o bienestar y no encuentran una ruta clara de acceso a los servicios de orientación.

2. **Problema — 45 s**
   - La información está dispersa entre instituciones, redes y conocimiento informal.
   - El joven hoy busca por sus propios medios (redes, familia, amigos, buscadores).
   - VibraLink aporta un punto de entrada claro, informativo y comunitario.

3. **Solución y demo — 1 min 30 s**
   - Directorio de servicios (búsqueda + filtros) y agenda comunitaria (búsqueda + filtros).
   - Ficha de detalle con fuente oficial, fecha de consulta, estado de verificación y contacto.
   - Registros ficticios para la demo; el único real («Yo Te Escucho») queda **pendiente**.

4. **Evidencia y TRL — 45 s**
   - `npm run build` ✔, `npm run lint` ✔, `npm test` (36 pruebas) ✔, `npm run validate:data` ✔.
   - TRL 4 demostrado en entorno controlado con datos sintéticos; limitaciones registradas.

5. **Equipo y próximos pasos — 30 s**
   - Cierre del ciclo de verificación de fuentes y obtención de fecha de consulta
     para el registro real.

## Regla del jurado aplicada

- No diagnostica, no prescribe, no predice riesgo, no usa datos reales de salud mental
  y no publica como servicio de salud: es un directorio informativo.
- Ningún teléfono se muestra como vigente sin fuente oficial y fecha de consulta.
- Los datos de prueba no contienen información personal ni clínica.
